# 平台打点脚本（M0）

这组脚本只做一件事：**用真实凭证调一次真实接口，把"能不能拿到会议内容"这个问题变成一张表。**

它是整个上架计划里唯一无法靠推演解决的未知数——三家平台都不保证能通过 API 拿到会议全文/转写。
结论出来之前，不要投钱做 `tabCapture`，也不要买 ASR 额度。

---

## 怎么跑

三个脚本彼此独立，都需要**只读**凭证，都不写文件、不落库、不打印完整密钥。

```powershell
# 飞书
$env:FEISHU_APP_ID="cli_xxx"
$env:FEISHU_APP_SECRET="xxx"
node scripts/spike/feishu.mjs
# 拿到一次真实会议后，追加：
$env:FEISHU_MEETING_ID="xxx"; node scripts/spike/feishu.mjs

# 企业微信（先跑自建应用，不需要上架）
$env:WECOM_CORP_ID="ww_xxx"
$env:WECOM_CORP_SECRET="xxx"
node scripts/spike/wecom.mjs

# 腾讯会议
$env:TENCENT_APP_ID="..."
$env:TENCENT_SDK_ID="..."
$env:TENCENT_SECRET_KEY="..."
$env:TENCENT_USER_ID="admin@example.com"
node scripts/spike/tencent.mjs
```

退出码：`0` 全部通过 / `1` 有失败项 / `2` 缺环境变量。

### 凭证从哪来

| 平台 | 入口 | 拿到凭证预计耗时 |
|---|---|---|
| 飞书 | 开放平台 → 创建**企业自建应用** → 凭证与基础信息 | 10 分钟（不需要审核） |
| 企微 | 管理后台 → 应用管理 → 创建自建应用 → 查看 secret | 10 分钟（需要企业管理员） |
| 腾讯会议 | 开放平台 → 创建应用 → 企业管理员授权 | 半天到 2 天（要等管理员审批） |

**先用自建/内部应用打点，不要一上来就去申请商店应用**：自建应用不需要权限审核，
能立刻回答"接口通不通"；商店应用的权限审批要等，等你确认这条路值得走再去排。

## 怎么读结果

| 现象 | 含义 | 下一步 |
|---|---|---|
| `判定=OK` | 凭证有效、权限已开、路径正确 | 记进报告 |
| 业务码 `99991672` / `60011` / `48002` | **权限没申请**或被拒 | 去后台申请对应 scope，记下审批耗时 |
| `HTTP 404` + 业务码 `404` | 路径不对（API 版本演进过） | 这条**不代表没有能力**，去查最新文档再试 |
| `HTTP 401` / 签名类错误 | 签名算法或编码不对 | 腾讯会议先切 `TENCENT_SIGNATURE_ENCODING=hex` |
| `HTTP 0` + `_error` | 网络/DNS 问题 | 先确认机器能访问外网 |

> 打点报告里最有价值的往往不是"OK"，而是**被哪个权限码挡住、审批花了多久**——
> 它决定上架时间线，而不是功能实现。

## 要记录的字段

把结果填进 [`docs/platform-spike-report.md`](../../docs/platform-spike-report.md)。每个平台记一行：

| 字段 | 说明 |
|---|---|
| 应用类型 | 自建 / 商店 |
| 能否拿到企业级 token | 是/否 + 错误码 |
| 能否拿到用户身份（免登） | 是/否 + 用的是 code 换还是 JSAPI |
| 能否读通讯录 | 是/否 + 需要哪个 scope |
| 能否列出**已结束**会议 | 是/否 + 接口路径 |
| 能否拿到录制文件 | 是/否 + 下载地址有效期（**关键**） |
| 能否拿到**转写文本** | 是/否（决定要不要自建 ASR） |
| 需要什么版本/付费等级 | 免费版 / 专业版 / 企业版 |
| 权限申请耗时 | 小时/天，是否被拒 |
| 关键错误码 | 原样记下来 |

## 判定标准（写进报告的结论行）

M0 的结论只允许三种，必须选一个：

1. **能拿到转写文本** → 最省事，走第 1 级降级链，ASR 可以延后
2. **只能拿到录制文件** → 必须做服务端 ASR（第 2 级），成本模型要重算
3. **什么都拿不到** → 只能靠用户手动上传（第 3 级），此时"AI 纪要"在该平台不是差异化功能，
   产品定位要改成"待办跟踪 + 合规留档"

结论 3 一旦成立，就触发 [`docs/platform-integration-plan.md`](../../docs/platform-integration-plan.md) §11 的止损条件。
